# APK-файл приложения «Критические дни»

Этот каталог содержит собранный APK:

- `critical-days-debug.apk` — debug-сборка приложения для отметки критических дней.

Установка на Android:

1. Скопируйте APK на устройство.
2. Разрешите установку из неизвестных источников (если требуется).
3. Откройте APK и установите приложение.
